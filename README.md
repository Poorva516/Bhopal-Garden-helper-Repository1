# Bhopal Garden Helper 🌱 - Touch Grass Edition

Simple offline garden app for Bhopal.
Works without internet - made for my terrace.

### What it does? (6 Steps) ###
1. Checks month - October
2. Tells what to plant - Coriander, Spinach, Tomato, Radish
3. Calculates how many plants in 20 sq ft
4. Water reminder
5. Sunlight check
6. Counts steps - Did you touch grass?
